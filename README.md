# Vegeta - CLI Data Converter

Vegeta is a lightweight, blazing-fast Command Line Interface (CLI) tool written in Go that seamlessly converts files between YAML and JSON formats and manages data persistence via PostgreSQL.

Built with the Cobra framework, Vegeta empowers developers to handle data pipelines with "Super Saiyan" efficiency—offering a full suite of CRUD operations to bridge the gap between local configuration files and robust database storage.
